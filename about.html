Introduction

My name is DeMarco Walker, and I am an Information Technology student at Kennesaw State University. My area of interest is Data Analytics, and I enjoy learning how technology works and how it can be used to solve problems.

Why I Chose HTTP

I chose HTTP because it is one of the main technologies behind the World Wide Web. Understanding how browsers and servers communicate is important for anyone studying Information Technology.

About This Project

This website was created for my IT 3203 Introduction to Web Development course. It explains the history of HTTP, how the protocol works, and important concepts related to web communication.

What I Learned

Through this project, I practiced writing HTML, using an external CSS stylesheet, creating navigation links, and organizing information across multiple webpages.
