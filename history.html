Introduction

HTTP has changed significantly since the early days of the World Wide Web. Each version introduced improvements that helped websites become faster, more reliable, and capable of handling modern content.

HTTP/0.9

HTTP/0.9 was introduced around 1990. It was a simple protocol that allowed browsers to request HTML documents using the GET method.

HTTP/1.0

HTTP/1.0 was documented in 1996. It introduced features such as headers, status codes, and support for different types of content.

HTTP/1.1

HTTP/1.1 was standardized in 1997. It improved performance by allowing persistent connections, which reduced the need to create a new connection for every request.

HTTP/2

HTTP/2 was standardized in 2015. It introduced binary framing, multiplexing, and header compression to improve communication efficiency.

HTTP/3

HTTP/3 was standardized in 2022. Unlike earlier versions, it uses QUIC over UDP instead of TCP. This helps reduce certain delays and improves performance when network conditions change.
